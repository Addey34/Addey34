# AG Signal V8.2 — recommended mixed composition

This is not a third visual direction. It is a **usage rule** for the same Signal system.

## Recommended density map

- **Dense:** section headers, navigation/actions, workflow steps, progression connectors.
- **Clean:** repeated content rows, technology stacks, state text, About content lines.
- **Dense selectively:** only the first/entry module of a repeated group when a stronger visual anchor is useful.

## Why

The directive rails and micro-nodes are the strongest part of Signal, but their impact is reduced if every repeated row carries the same density.

The intended rhythm is therefore:

**strong signal entry → clean information → strong transition → clean information**

This keeps the profile recognisable as AG without turning every line into interface decoration.

## Composition rule

1. Hero / navigation — strong signal.
2. About header — dense.
3. About content — clean.
4. Current header — dense.
5. Current title modules — dense.
6. Current stack + state — clean.
7. Workflow — dense throughout because progression is the content.
8. Toolkit header / category title — dense.
9. Toolkit rows — clean.
10. Contact actions / footer — dense.
