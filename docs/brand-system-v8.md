# AG Modular Interface — V8 prototype

This branch is a **card-system prototype**, not the public profile.

## Direction

The V8 system replaces the repeated gold-line / blue-rise motif with a modular interface language:

- broken-corner technical frames;
- left-side signal rails;
- gold and blue state nodes;
- numbered micro-labels;
- compact technology chips;
- asymmetric corner accents;
- small connection-node signatures;
- larger primary typography;
- consistent information hierarchy.

Gold represents authored structure. Electric blue represents active signal / movement.

## Current sizing

- wide module: 1120 px
- half module: 540 px
- primary card title: 24 px
- section title: 28 px
- body / secondary text: 12.5–15.5 px
- micro-label: 9.5–10.5 px
- chip label: 10.5 px

The final pass can increase type slightly once the GitHub layout width is locked.
