# AG Brand System — v1

## Intent

This is the permanent visual system for **Adrian Guichard / AG** across the GitHub profile and future personal-brand surfaces.

The system is designed to remain relevant if the technology stack changes. It is therefore based on **structure, motion and authorship**, not framework logos or trend-driven visual effects.

## Core idea — Arc / Cut / Signal

**Arc** represents systems, continuity, exploration and the `G` in the monogram.

**Cut** is the recurring authored gesture: a precise 14° interruption. It prevents the system from feeling generic or mechanically perfect.

**Signal** is the electric-blue line that moves through otherwise warm, structured gold forms. It represents active systems, realtime work and motion from idea to production.

The identity must still work with all effects removed and in a single color.

## Usage rules

1. **Gold is structural.** It identifies the author, framing, major dividers and the permanent brand layer.
2. **Electric blue is active.** It marks links, motion, status and current signals. It is not required inside the primary monogram.
3. **Project colors do not replace AG colors.** Project identities live inside an AG frame.
4. **No mandatory glow.** If the design only works because of bloom, gradients or neon, it is not finished.
5. **No framework-logo hero.** Technology belongs lower in the hierarchy than identity and work.
6. **One 14° cut per meaningful composition is enough.** Repetition makes the gesture decorative instead of distinctive.
7. **Whitespace is part of the identity.** Do not fill every available area.
8. **The primary monogram is flat gold or monochrome.** Metallic gradients are reserved for exceptional large-format artwork, never required for recognition.\n9. **The monogram must survive at 24 px and in monochrome.**

## Grid

- Primary SVG width: **1200 px**
- Outer safe margin: **72 px**
- Internal spacing unit: **8 px**
- Default corner radius: **24 px**
- Fine rule: **1 px**
- Structural rule: **2 px**
- Monogram stroke: **11 px**

## Typography

The profile must rely on system-safe fonts when text is embedded in SVG:

- Display / body: `Inter, Segoe UI, Arial, sans-serif`
- Technical microcopy: `SFMono-Regular, Consolas, Liberation Mono, monospace`

Large display text should use restrained negative tracking. Small technical labels use generous positive tracking.

## Signature phrase

Preferred permanent close:

**FROM IDEA TO RUNNING SYSTEM.**

This is a positioning line, not a slogan that must appear in every asset.


## Editorial restraint

The profile must not look like a generic cyber-dashboard or AI-generated "premium tech" concept.

- Rounded cards are not the default composition.
- Repeated micro-labels such as `AG // SYSTEM` are used sparingly, never as filler.
- Large typography, spacing and alignment carry the identity before decorative graphics.
- One section may intentionally behave like an instrument panel: GitHub live data.
- Gold is authored structure; electric blue is the active interruption.
- Effects are secondary. The system must remain convincing with flat color, no glow and no gradients.
- Project artwork may be expressive, but the AG frame stays quieter than the product identity.
- The profile should feel closer to an editorial identity system than a SaaS dashboard.
