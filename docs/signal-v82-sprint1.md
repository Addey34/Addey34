# AG Signal V8.2 — Sprint 1

This branch contains the first full **Signal-first atomic module library**.

The public profile README is unchanged.

## Variants

### Signal Clean
Prioritizes immediate reading:
- thin directive rails;
- one primary node per module;
- larger text;
- minimal system metadata;
- more breathing room.

### Signal Dense
Keeps the same layout contract but adds:
- secondary nodes;
- micro labels;
- short telemetry lines;
- stronger rails;
- additional endpoint details.

Dense must never change the information hierarchy; it only adds system texture.

## Current visual conclusion

Clean is the readability baseline.

Dense currently has the stronger AG identity because it preserves Clean's hierarchy while adding subtle signal metadata.

The final direction can therefore use **Dense selectively**, not uniformly: dense treatment for navigation, progression and section entry points; cleaner treatment for repetitive information rows.
